SEPARATE NATIVE APP · SETUP REQUIRED

Your first scene, today

NVIDIA instant-ngp can reconstruct a viewable neural scene from photographs. Its official repository links a Windows binary for RTX 3000 / 4000 cards.

  1. Get the official Windows package.
    Follow the RTX 3000 / 4000 release link in the repository below. Read the license before downloading.
  2. Extract the ZIP and launch instant-ngp.exe.
    This workspace does not download, install or execute it for you. Do not bypass Windows security warnings.
  3. Use the supplied NeRF fox dataset first.
    Drag the extracted data/nerf/fox folder into the instant-ngp window. Watch training begin, then orbit the scene. This sample needs no Python, COLMAP or personal photos.
  4. Then capture your own stationary object.
    Use overlapping photos from many viewpoints. A personal dataset also needs camera-pose preparation, usually via COLMAP; it is not simply an arbitrary photo folder.
