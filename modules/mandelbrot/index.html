    Numerical honesty, definitions & sources

    The mathematical set is infinite; this picture is a finite calculation. Each image pixel samples its center. Edges can contain details smaller than a pixel. Dark means no escape was detected within the chosen budget, or a conservative analytic shortcut recognized the quadratic main-cardioid or period-2-bulb interior. Neither pixel resolution nor floating-point arithmetic is a proof of the exact boundary.

    All orbit calculations use JavaScript’s IEEE 754 binary64 numbers (about 15–17 significant decimal digits). No single-precision GPU arithmetic is used. At high zoom, coordinate spacing and accumulated orbit error matter. We stop zooming at a horizontal span of 10⁻⁹ or a stricter coordinate-spacing guard. This is a conservative interface limit, not a guarantee of accuracy up to that depth. Arbitrary precision or perturbation methods would be needed for much deeper work.

    The quadratic Mandelbrot test uses the strict condition |zₙ| > 2. Touching radius 2 does not mean escape: c = −2 is the essential example.

    The filled Julia set is the set of starting values whose orbits stay bounded for a fixed c. The Julia set proper is its boundary. The smooth palette interpolates an escape-time estimate; changing a palette changes appearance only.
