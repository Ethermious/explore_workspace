What is actually happening?

Position integration runs on the GPU using WebGL 2 transform feedback: two particle buffers exchange roles every step. RK2 integration, four bounded substeps per displayed frame. CPU seeds particles; it does not integrate them.

Artistic dynamical-system exploration, not CFD, an engineering simulation, or a benchmark. FPS is observed browser frame cadence, not GPU execution time. No VRAM or temperature telemetry is available here.

Budget never increases automatically. Resolution is capped at 2560 × 1440 equivalent pixels; stop or choose Quiet if your machine feels busy. Hidden tabs pause; context loss stops the lab. Reload to restore.
